# Automatizalo Ya — Web

Web estática preparada para publicar gratis en GitHub Pages.

Archivos:
- index.html
- styles.css
- script.js
- logo.png

El formulario está preparado para conectarse a un webhook de n8n. Sustituye `TU_WEBHOOK_N8N` en `script.js` cuando tengas el webhook.

Para publicar:
1. Crea un repositorio público en GitHub.
2. Sube estos 4 archivos.
3. Ve a Settings → Pages.
4. Selecciona Deploy from a branch → main → /root.
5. Guarda y espera a que GitHub Pages publique la web.
